# Odinheim for Windows

**Odinheim** is a Norse online world: cross the nine realms, bring down the gods' beasts, forge your own arms.

## Play in your browser

Nothing to download: **https://odinheim.net**

## Download for Windows

**[Download Odinheim-Windows.zip](https://odinheim.net/download/windows)** — always the newest version.

1. Right-click the downloaded zip and choose **Extract All**.
2. Open the **Odinheim** folder and double-click **Odinheim.exe**.

It starts fullscreen; F11 (or Alt+Enter) switches to a window. Your hero comes with you: choose **Hero Code** on the title screen and type the code from the top of your Skills panel.

The downloaded game does not update itself. When a newer version is out it tells you as it starts, with a button that fetches it.
